# Cryptography from Scratch

A structured collection of cryptographic algorithms implemented from scratch in Python, with mathematical explanations, worked examples, testing, and cryptanalysis.

## Objectives

- Understand the mathematical foundations of cryptography.
- Implement classical and modern cryptographic algorithms.
- Explore encryption, decryption, and key management.
- Study cryptographic weaknesses through practical experiments.
- Develop a foundation for future AI-based cybersecurity projects.
